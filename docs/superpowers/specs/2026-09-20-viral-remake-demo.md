# 爆款复刻前端 Demo 设计规格

## 目标

在现有 Agent Kit 中新增一个 PC 优先、完整可点击的「爆款复刻」前端 Demo。首屏展示三种复刻模式，仅「元素替换」可进入；进入后按方案 A 的全宽阶段式工作台完成五步演示。

## 页面结构

1. 模式选择：元素替换、原片仿写、结构仿写。后两项显示「即将上线」。
2. 接收需求：从空白上传态开始，可加载 Demo；支持模板视频、替换描述、多项素材、Seedance 模型选择。
3. 拆解视频：展示处理状态、拆解脚本与三张原视频逐秒分镜总览图。
4. 替换元素：展示可编辑故事面板及三组原片/替换后分镜对照，支持保存与重新生成。
5. 提取片段：展示三个可编辑片段脚本，支持保存与重新提取。
6. 生成视频：展示三个片段卡片，可查看故事面板、单独生成或批量生成，并演示生成状态。

## 交互规则

- 空白上传页可通过真实文件选择器添加素材；「加载 Demo 素材」填入用户提供的演示数据。
- 下一步按钮推进流程，顶部步骤可回看已完成步骤，不能跳过未完成步骤。
- 文本编辑保存到浏览器 localStorage；刷新页面后保留。
- 重新生成仅模拟状态变化和进度，不调用真实模型。
- 生成视频仅模拟排队、生成中、完成状态。
- 所有关键按钮可键盘访问，弹层可关闭，操作结果通过页面提示反馈。

## 视觉方向

- 采用确认的方案 A：顶部五步进度，全宽内容舞台，当前产物为视觉主体。
- 延续 Agent Kit 的思源黑体、语义颜色令牌、间距、圆角、阴影和 Lucide 图标。
- PC 为主要展示尺寸，同时保证项目规范要求的窄屏不溢出。
- 不使用渐变、玻璃拟态、霓虹色或夸张阴影。

## 非目标

- 不接入真实 Gemini、GPT、图像或 Seedance 接口。
- 不实现原片仿写与结构仿写流程。
- 不新增后端、账号、计费、任务队列或云端存储。
