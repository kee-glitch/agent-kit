# 爆款复刻前端 Demo 现状版设计规格

## 1. 文档目的

本文档准确描述当前已经实现并可运行的「爆款复刻」前端 Demo。它是页面现状、交互规则、状态结构和验收范围的统一基线，不包含真实模型、后端任务队列或云端服务的未来设计。

页面入口为 `#/remake`，当前仅开放「元素替换」模式。

## 2. 产品目标

「爆款复刻」用于演示短视频元素替换流程。用户从空白项目开始，选择元素替换模式，上传需要复刻的视频，配置替换素材与替换要求，查看模拟生成的分镜和故事面板，并按片段发起视频生成。

当前版本的成功标准是：用户无需后端服务即可完整点击演示全部流程；上传项可以新增、替换和删除；替换需求可以引用素材；故事面板可以编辑和保存；片段生成具备清晰的待生成、生成中和完成反馈。

## 3. 产品范围

### 3.1 当前支持

- 展示「元素替换」「原片仿写」「结构仿写」三种模式。
- 仅「元素替换」可以进入工作台。
- 上传、替换和删除模板视频。
- 选择四种 Seedance 模型。
- 选择最终视频画面比例。
- 一键加载完整 Demo 数据。
- 查看视频拆解文档和原视频逐秒分镜。
- 按原片识别对象上传对应替换素材。
- 额外添加图片、音频和视频素材。
- 使用「图片1」「图片2」「音频1」「视频1」等序列名称管理素材。
- 在替换需求中输入 `@` 引用已上传素材。
- 查看原片与替换后分镜对照。
- 编辑、保存和模拟重新生成故事面板。
- 查看片段故事面板，选择片段后单独或批量模拟生成视频。
- 在当前浏览器保存和恢复项目草稿。

### 3.2 当前不支持

- 不调用 Gemini、GPT、图像生成或 Seedance 接口。
- 不实际执行 FFmpeg 视频抽帧。
- 不生成真实视频文件。
- 不实现账号、权限、云端项目或跨设备同步。
- 不实现后端任务队列、失败重试或计费。
- 不开放「原片仿写」和「结构仿写」。
- 不以移动端适配作为交付目标。

## 4. 页面结构与用户流程

### 4.1 模式选择页

用户进入页面后首先看到三张模式卡片：

- 元素替换：当前可用，可进入创建流程。
- 原片仿写：显示「即将上线」，不可进入。
- 结构仿写：显示「即将上线」，不可进入。

页面提供模式说明和「如何选择」提示，不自动进入工作台。

### 4.2 元素替换工作台

工作台由项目头部、四阶段进度条、当前阶段内容区和操作反馈组成。

项目头部包含：

- 返回模式选择。
- 当前项目名称。
- 重新开始。
- 保存草稿。

顶部阶段依次为：

1. 拆解视频。
2. 替换素材。
3. 替换结果。
4. 提取片段。

用户只能访问已经解锁的阶段，不能跳到尚未完成的阶段；可以返回已解锁阶段修改内容。

### 4.3 STEP 01：拆解视频

初始状态为空白上传页。用户可以：

- 上传 MP4 或 MOV 模板视频。
- 替换或删除已上传视频。
- 选择 Seedance 模型。
- 选择最终视频画面比例。
- 一键加载 Demo 数据。

只有上传模板视频后，「开始拆解视频」按钮才可用。替换或删除模板视频会使旧拆解结果和生成状态失效，防止旧结果继续关联新视频。

### 4.4 STEP 02：选择替换素材

页面在宽屏下采用左右工作区：

- 左侧展示视频拆解文档和三张原视频逐秒分镜。
- 右侧配置替换素材和替换需求。

系统根据 Demo 拆解结果提供三个固定原始对象槽位：

- 人物1。
- 产品1－单粒特写。
- 产品1－瓶装。

每个固定槽位可以上传、替换或清空对应图片。用户还可以新增任意图片、音频和视频素材。

普通素材按类型自动编号：

- 图片从图片4开始。
- 音频从音频1开始。
- 视频从视频1开始。

前三个图片编号预留给固定对象槽位。删除素材后不复用旧编号，避免既有 `@素材` 引用指向错误对象。

替换需求为非必填项。输入 `@` 后出现素材候选菜单，用户可以通过鼠标或键盘选择素材引用。

### 4.5 STEP 03：校对替换结果

页面展示：

- 三组原视频逐秒分镜。
- 三组替换后逐秒分镜。
- 替换后的故事面板。

用户可以放大查看分镜、直接编辑故事面板、保存修改或触发模拟重新生成。模拟重新生成不会覆盖用户当前编辑内容。

### 4.6 STEP 04：片段故事面板

当前 Demo 将片段提取和视频生成合并在同一阶段，展示三个片段：

- 片段01：00:00–00:15。
- 片段02：00:15–00:30。
- 片段03：00:30–00:41。

用户可以：

- 查看片段摘要和完整故事面板。
- 选择或取消选择片段。
- 全选或取消全选。
- 单独生成某个片段。
- 批量生成选中的片段。
- 对已完成片段重新生成。

生成过程只模拟状态变化，不输出真实视频。

## 5. 项目状态与数据规则

### 5.1 项目状态

页面以单一项目状态保存当前工作进度，主要包括：

- 当前阶段和已解锁的最高阶段。
- 模板视频名称。
- Seedance 模型。
- 画面比例。
- 替换需求。
- 替换素材列表及各类型编号计数。
- 拆解文档、故事面板和片段文档。
- 每个片段的视频生成状态。

页面初始化时从浏览器 `localStorage` 恢复已保存草稿。损坏或类型不正确的字段回退到安全默认值。

### 5.2 模板视频规则

- 未上传模板视频时不能进入第二阶段。
- 替换模板视频后保留替换需求和素材，但清空旧视频对应的拆解文档与生成状态。
- 删除模板视频后回到第一阶段，并锁定后续阶段。
- 本地视频二进制内容不写入 `localStorage`，只保存文件名称等轻量信息。

### 5.3 固定替换素材

固定素材通过原始对象 ID 保持绑定关系：

| 原始对象 ID | 页面对象 | 素材名称 |
| --- | --- | --- |
| `person` | 人物1 | 图片1 |
| `product-bottle` | 产品1－瓶装 | 图片2 |
| `product-detail` | 产品1－单粒特写 | 图片3 |

同一个固定槽位始终只保留一个素材。再次上传时替换旧素材，不新增重复条目。固定槽位仅接受图片文件。

### 5.4 通用替换素材

通用素材支持图片、音频和视频，可以批量上传、单项替换和单项删除。

系统按照媒体类型分配稳定序号。跨类型替换时重新分配符合新类型的名称，并推进对应类型的编号计数。

### 5.5 素材引用

替换需求编辑器支持输入 `@` 召回素材：

- 候选项按图片、音频和视频的序列名称匹配。
- 支持键盘上下选择、回车确认和 Esc 关闭。
- 素材引用作为完整单元插入。
- 输入内容最多 500 个字符。
- 如果新输入超过上限，保留上一次完整有效内容，不截断素材引用。
- 删除素材不会自动重写已有文本，由用户自行校对失效引用。

### 5.6 文档编辑

故事面板和片段内容以 Markdown 展示。阅读态支持标题、列表、表格和素材引用标记。

用户可以进入编辑态修改正文。编辑过程实时写入当前项目状态；故事面板内的「保存」和顶部「保存草稿」都会把完整项目写入浏览器存储。模拟重新生成只改变加载状态和提示，不覆盖用户编辑内容。

### 5.7 生成状态

每个片段独立维护以下状态：

- `idle`：待生成。
- `running`：生成中。
- `done`：已完成。

批量生成只启动当前未运行的片段，避免重复计时器。离开相关页面或组件卸载时，运行中的模拟任务恢复为可重试状态。

## 6. 交互与可访问性

- 分镜图片支持大图预览。
- 片段支持完整故事面板弹层。
- 弹层可以通过关闭按钮、Esc 或点击遮罩关闭。
- 弹层打开时锁定页面滚动，并将键盘焦点限制在弹层内。
- 弹层关闭后将焦点返回原触发控件。
- 保存、加载 Demo、重新生成和生成完成等操作通过 Toast 提示。
- 当前阶段、已完成阶段、禁用阶段和生成状态均有文字与视觉双重表达。
- 所有关键按钮具备可见焦点样式和可读标签。

## 7. 视觉与响应式规范

### 7.1 视觉方向

页面延续 Agent Kit 现有设计系统：

- 使用项目现有字体体系。
- 背景、文字、边框、状态色、阴影、圆角和间距引用现有语义变量。
- 主要操作使用深色实心按钮，次要操作使用白色描边按钮。
- 图标统一使用 `lucide-react`。
- 卡片通过边框、背景层级和轻量阴影区分。
- 局部渐变只用于内容折叠遮罩，不作为品牌装饰。

### 7.2 桌面布局

- 模式选择页内容最大宽度为 1280px，三张模式卡片横向排列。
- 工作台保留 Agent Kit 左侧主导航。
- STEP 02 在宽屏下采用「左侧拆解结果 + 右侧替换配置」布局。
- 右侧替换配置在桌面端保持可见，内容过长时区域内部滚动。
- 分镜对照在宽屏下左右并排，分镜总览默认三列展示。
- 弹层最大宽度约 1320px，并限制在当前视口内滚动。

### 7.3 信息层级

每个阶段统一包含：阶段编号、页面标题、任务说明、状态或主要操作、核心内容卡片，以及底部返回和继续操作。

文档、素材、分镜和片段使用不同卡片结构，但保持统一的标题、辅助说明、边框和操作位置。

### 7.4 关键交互视觉

- 当前阶段使用深色圆形编号，已完成阶段使用成功色。
- 未解锁阶段使用弱化文字和禁用状态。
- 素材上传区使用虚线边框。
- 已上传素材显示缩略图、序列名称和原文件名。
- 删除操作使用错误色，但保持较低视觉权重。
- `@素材` 引用使用独立标签样式。
- 生成状态使用「待生成」「生成中」「已完成」标签。
- 可点击图片提供放大提示。
- 键盘焦点使用统一可见描边。

### 7.5 响应式行为

产品以 PC 演示为主要目标，同时保留基础窄屏适配。

在 1050px 以下：

- STEP 02 左右工作区改为上下排列。
- 右侧素材配置取消粘性定位。
- 原片与替换后分镜改为单列。
- 生成概览调整为两列。

在 820px 以下：

- 三张模式卡改为单列。
- 四阶段步骤条允许横向滚动。
- 分镜总览改为单列。
- 页面标题和操作区域改为纵向排列。
- 隐藏部分非关键头部操作文字或按钮。

在 620px 以下：

- 素材槽位和生成卡片进一步改为单列。
- 视频选项改为单列。
- 阶段底部按钮占满宽度。
- 主导航宽度缩小。
- 模态框正文减少左右留白。

页面响应系统的「减少动态效果」设置，关闭卡片过渡和加载旋转动画。

当前 Demo 使用现有 React + Vite 前端架构，不新增后端或状态管理库。

## 9. 数据流与模拟任务

页面初始化流程：

1. 从 `localStorage` 读取草稿。
2. 通过状态恢复函数校验字段。
3. 无有效草稿时创建空项目。
4. 用户操作通过纯状态函数生成新状态。
5. 用户点击「保存草稿」时持久化项目。

本地媒体预览使用浏览器读取结果，只保留在当前页面状态中。保存草稿时移除媒体二进制内容，避免超过浏览器存储容量。

拆解、替换和视频生成均不访问外部接口：

- 「开始拆解」进入预置拆解结果。
- 「生成替换结果」进入预置故事面板和分镜。
- 「重新生成」使用短计时器模拟处理中状态。
- 单段及批量生成使用独立计时器模拟完成状态。
- 页面卸载时清理计时器，避免组件销毁后继续更新状态。

## 10. 异常与边界处理

- 文件选择为空时不修改状态。
- 同一固定槽位的异步读取只接受最后一次选择结果。
- 删除素材后，迟到的旧文件读取结果不能重新写回。
- 损坏草稿回退到安全默认状态。
- 不支持的画面比例回退为 `9:16`。
- 模板视频为空时锁定后续阶段。
- 重复点击正在生成的片段不会创建重复任务。
- 超过 500 字符的替换需求不会破坏完整素材引用。
- 弹层关闭后恢复触发控件焦点。

## 11. 测试与验收

### 11.1 自动化测试范围

- 阶段推进、回退和未解锁访问。
- 模板视频替换与删除后的状态失效。
- 固定素材绑定关系。
- 普通素材稳定编号。
- 跨类型替换和删除后的编号连续性。
- `@素材` 过滤、键盘选择和定位。
- 文本长度边界。
- 草稿保存、恢复和损坏数据回退。
- 片段选择、批量排队和状态复位。
- 弹层遮罩判断和焦点循环。
- Demo 文档、素材路径和片段内容完整性。

### 11.2 浏览器验收标准

1. 首屏正确展示三张模式卡片。
2. 只有「元素替换」可进入。
3. 空白状态下不能开始拆解。
4. 视频可以上传、替换和删除。
5. 加载 Demo 后可以走完四个阶段。
6. 固定素材和普通素材均可新增、替换和删除。
7. `@` 菜单可以通过鼠标和键盘选择素材。
8. 故事面板可以编辑和保存。
9. 刷新后已保存文本仍然存在。
10. 原片与替换后分镜可以放大查看。
11. 片段可以单独生成、选择生成和重新生成。
12. 生成中按钮不可重复触发。
13. 弹层支持 Esc、遮罩和关闭按钮。
14. 1050px、820px 和 620px 附近布局无关键内容遮挡。
15. 浏览器控制台无运行时错误。

## 12. 当前整理项

早期五步流程遗留的 `StepFive` 组件已经删除，四阶段步骤数据、页面渲染和回归测试保持一致。

除补齐已确认的故事面板直接编辑与保存能力、删除遗留组件和同步文档外，现状版整理不扩展真实模型、后端服务或其他复刻模式。
